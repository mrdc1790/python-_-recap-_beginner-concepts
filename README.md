# Python beginner exercises

A collection of early Python exercises covering terminal input, loops, game state, and algorithms. Start with [binary search](little%20projects%20%28easy%20diff%29/05-BinarySearch/binary_Search.py) for a compact algorithm example or [Minesweeper](little%20projects%20%28easy%20diff%29/06-minesweeper/minesweeper.py) for a larger terminal program. The [tutorials](tutorials/) are grouped by topic.

## Run the binary search example

Run the binary search example with Python 3 from the repository root:

```sh
python "little projects (easy diff)/05-BinarySearch/binary_Search.py"
```
